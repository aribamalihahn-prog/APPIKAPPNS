# IKAPPNS Mobile Application

A smartphone-based mobile application developed for Ikatan Alumni Politeknik Perkapalan Negeri Surabaya (IKAPPNS) to facilitate alumni information management, communication, and digital services.

## Technology
- React Native
- Expo Framework
- JavaScript / TypeScript

## Features
- Alumni data management
- Alumni information access
- Digital communication platform
- User-friendly mobile interface
- Alumni service support

## Project Overview
IKAPPNS Mobile Application is designed to provide a digital platform for managing alumni-related information and improving communication between alumni members. The application supports easier access to alumni services and information through a smartphone-based platform.
